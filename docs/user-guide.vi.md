# Hướng Dẫn Người Dùng

1. Mở MiyoMacroSentinel.
2. Vào **Quét một file**, kéo thả tài liệu hoặc bấm **Chọn file**.
3. Bấm **Quét**.
4. Đọc huy hiệu rủi ro và phần tóm tắt trước.
5. Xem các tab phát hiện, IOC, ký tự ẩn, và giải mã tĩnh.
6. Mở báo cáo HTML/JSON trong thư mục report cục bộ.

Không mở file High hoặc Critical. Không bấm **Enable Content** trong Office. Gửi file nghi ngờ cho IT/SOC.
