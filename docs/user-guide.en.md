# User Guide

1. Open MiyoMacroSentinel.
2. Use **Single File Scan** and drag/drop a document or choose **Browse**.
3. Press **Scan**.
4. Read the risk badge and beginner summary first.
5. Use the tabs for findings, IOCs, hidden characters, and decoded text.
6. Open the local HTML/JSON reports from the report folder.

Do not open High or Critical files. Do not click **Enable Content** in Office. Send suspicious files to IT/SOC.
